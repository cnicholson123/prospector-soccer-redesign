# ChrisBot deployment review gate (2026-11-09) — fixes required before deploy

From ChrisBot's independent review of commit 7f545fd (no critical issues):
1. **Media revocation/CDN** (server/media.ts ~152–176): published media is served with `s-maxage=86400` and no content cache tag, so unpublished/superseded media can stay publicly cached for 24h. Fix: tag media responses with the content cache tag (so publish/unpublish/trash purge them like pages) AND use a short shared TTL as a bounded fallback (e.g. `public, max-age=0, s-maxage=300, stale-while-revalidate=60`). Update README text that says 24h.
2. **Upload quota replay** (server/http/routes/media.ts ~24–31): quota is charged at ticket issuance and signed grants stay reusable for 15 min; finalize deletes incoming paths so a grant can be replayed for upload/replace, creating more retained copies without byte accounting. Fix: make each grant single-use with atomic consumption at finalize (store-backed, FS + Postgres) with idempotent retry of the same finalize (same result, no second copy), and/or charge quota on actually accepted bytes. Regression tests: replaying a consumed grant → rejected; retrying a finalize that failed before commit still works.
3. **Temporary password loophole** (server/http/routes/auth.ts ~75–85): changing password accepts next === current and both stores clear mustChangePassword. Fix: when mustChangePassword is set (and in general), reject a new password equal to the current one; only clear the flag after a genuinely different password. Regression tests for create and reset flows.

Also: e2e at 1280px very occasionally records the benign Chrome page error "Transition was aborted because of invalid state. ViewTransition opt-in disabled" when navigating from the public site (cross-document view transitions) into the admin. Mitigate in public/assets/js/main.js if possible (e.g. register the pageswap/pagereveal handlers as early as possible / skip transitions for any link into /admin before navigation via a click listener that sets a flag), and in tests ignore ONLY that exact benign message with a comment.
